# Data Redundancy Removal System

## Overview

This project detects and removes redundant data before storing records in a MySQL database.

## Features

- Exact Duplicate Detection
- Fuzzy Matching
- Similarity Score Calculation
- FastAPI Backend
- MySQL Integration
- Swagger UI Testing

## Technologies

- Python
- FastAPI
- MySQL
- SQLAlchemy
- FuzzyWuzzy

## Run Project

```bash
uvicorn main:app --reload
```
